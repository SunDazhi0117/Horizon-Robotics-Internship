# SceneCode

## Problem

Many generated scenes are static and lack interaction capabilities.

Robots require environments that contain interactive objects and executable interactions.

## Input

* Text Prompt

## Output

* Scene Programs
* Interactive Scenes
* Functional Objects

## Key Idea

SceneCode represents scenes as executable programs rather than static geometry.

This allows the generated environments to contain interactive objects and interaction logic.

## Position in Embodied AI Pipeline

Interactive Scene Generation

## Personal Understanding

SceneCode fills the gap between static scene generation and robot interaction.

Compared with SceneSmith, it introduces functionality and interaction into generated scenes, making them more suitable for embodied AI tasks.
