# Articulate-Anything

## Problem

Creating articulated objects manually requires significant human effort and domain knowledge. The process is difficult to scale for embodied AI training.

## Input

* Text
* Images
* Videos

## Output

* Articulated Objects
* Interactable Digital Twins

## Key Idea

Articulate-Anything uses vision-language models and foundation models to automatically generate articulated objects from multimodal inputs.

The generated objects contain joints and motion structures that robots can interact with.

## Position in Embodied AI Pipeline

Articulated Object Generation

## Personal Understanding

Articulate-Anything focuses on generating robot-operable objects.

Instead of creating static 3D models, it generates objects with joints and motion constraints, allowing robots to perform interaction tasks such as opening doors, pulling drawers, and manipulating cabinets.
