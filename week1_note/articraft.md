# ArtiCraft

## Problem

Embodied AI systems require large quantities of 3D assets and datasets.

Creating these assets manually is expensive and difficult to scale.

## Input

* Text Prompt

## Output

* 3D Assets
* 3D Models
* Datasets

## Key Idea

ArtiCraft automatically generates large-scale 3D assets and datasets that can be used for simulation, training, and evaluation.

The project aims to reduce human effort in asset creation and data collection.

## Position in Embodied AI Pipeline

Asset Generation

## Personal Understanding

ArtiCraft serves as the foundation of the embodied AI pipeline.

It provides the assets that are later used to build scenes, interactive environments, and robot tasks.
