# SceneSmith

## Problem

Creating large-scale simulation environments manually is expensive and time-consuming.

Embodied AI systems require diverse and realistic scenes for robot training and evaluation.

## Input

* Text Prompt

## Output

* Complete 3D Scenes
* Physically Plausible Environments

## Key Idea

SceneSmith automatically generates complete simulation environments from text descriptions.

The generated scenes contain reasonable object placements and layouts that can support robot interaction and navigation.

## Position in Embodied AI Pipeline

Scene Generation

## Personal Understanding

SceneSmith focuses on generating the environment in which robots operate.

Compared with asset generation methods, SceneSmith is responsible for constructing complete scenes rather than individual objects.
