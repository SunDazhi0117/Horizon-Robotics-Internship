# Week10 task configs

- `file_drawer_open_close.yaml`: one longer prismatic manipulation with mobile
  base synchronization and full restoration.
- `dishwasher_door_rack_restore.yaml`: a two-target composite task combining a
  horizontal hinge and a rack slide. The robot opens the door, releases it,
  pulls and restores the rack, regrasps the door from above, closes it, and
  returns home.

Both configs use the shared Week9 runtime and runner.
